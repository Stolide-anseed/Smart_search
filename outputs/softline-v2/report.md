# Допродажи Softline V2

Замер от 26 ноября 2026 года на XML-снимке с 136 040 предложениями. Baseline записан до изменений. Сравнительные метрики рассчитаны по одинаковым ID основных товаров и контекстам. При пересчёте из 44 исходных ноутбуков исключена карточка планшетного ПК. Из 420 карточек широкой офисной выборки под сценарий попали шесть пакетов. Среди остальных были MDM, облачные услуги, отдельные инструменты и комплекты с антивирусом.

Coverage — доля применимых основных товаров хотя бы с одной рекомендацией. Available Coverage — доля с рекомендацией, доступной по фиду и имеющей положительную цену. В этом замере Available Coverage совпало с Coverage во всех строках обеих версий.

Ранний замер без уточнённой применимости давал 1 из 44 для ноутбуков и 5 из 420 для офисного ПО. Эти исходные числа сохранены в [baseline](recommendations-baseline.json).

Для подбора антивируса нужны ОС и число устройств. У четырёх офисных пакетов подтверждено несколько платформ. Только число рабочих мест оставляет ОС неопределённой. При запросе десяти компьютеров под Windows пять офисных SKU исключены по их фиксированному числу компьютеров или по документированному пределу настольных установок. Проверены конкретные пары по паспортам производителей, условиям лицензий и явным полям фида. У baseline была одна рекомендация со спорным числом устройств, оставленная без оценки precision. У V2 все рекомендации на этих 22 случаях размечены. Полнота по всему каталогу остаётся неизмеренной из-за неполной разметки и характеристик. [Проверочные случаи и основания](../../tests/fixtures/softline_recommendations.json)

Пример новой пары. У ThinkBook 16 G8 IRL глубина 253,5 мм. Предел сумки HP A08JWAA составляет 240 мм по глубине, рюкзака HP A08JXAA — 270 мм. Для этого ноутбука проходит рюкзак. [Lenovo PSREF](https://psref.lenovo.com/Product/ThinkBook/ThinkBook_16_G8_IRL), [паспорт сумки HP](https://www.hp.com/ie-en/products/accessories/product-details/product-specifications/2102293041), [паспорт рюкзака HP](https://www.hp.com/ie-en/products/accessories/product-details/product-specifications/2102293045)

## Причины пустой выдачи

| Сценарий без уточнений | Причины в V2 |
| --- | --- |
| ИБП APC | У 13 ИБП отсутствует ссылка на точный артикул батареи. Для девяти требуемого артикула нет в каталоге. |
| Ноутбуки | У 19 карточек нет подтверждённых габаритов корпуса. Из 30 кандидатов в категории сумок и чехлов технические размеры подтверждены для двух моделей. Для остальных нужны данные о внутренних размерах или точный список совместимых моделей. |
| Офисные пакеты | Для трёх пакетов требуется количество устройств, для одного также нужно уточнить ОС. У MobiOffice Lifetime без уточнения ОС требуется поддержка Windows и macOS. Среди подтверждённых лицензий такой пары в замере нет. |

Паспортные характеристики добавлены для десяти моделей ноутбуков, двух аксессуаров HP и четырёх артикулов MobiOffice. Справочник применяется к 28 уникальным артикулам в XML. Из 11 038 кандидатов в категории корпоративных антивирусов 357 имеют достаточно подтверждённых данных для проверки с пользовательским контекстом. Остальные учтены в диагностике. [Справочник](../../softline_search/compatibility_specs.json), [результаты по каждому товару](recommendations-v2.json)

## Время и память

| Показатель | Baseline | V2 | Изменение |
| --- | ---: | ---: | ---: |
| p50 подбора | 0,004 мс | 0,136 мс | +0,132 мс |
| p95 подбора | 3,55 мс | 5,12 мс | +1,57 мс |
| Максимальное время подбора | 6,16 мс | 7,28 мс | +1,12 мс |
| Подготовка рекомендательного индекса | 11,09 с | 15,63 с | +4,54 с |
| Память процесса после подготовки | 179,8 МиБ | 184,4 МиБ | +4,7 МиБ |

Замер подбора включает 110 сопоставимых вызовов агента после построения индекса с выключенной диагностикой. Подготовка и прогон V2 заняли 16,09 с. Рабочий набор процесса рекомендаций после прогона составил 184,8 МиБ, пик — 196,3 МиБ. Загрузка поисковой модели E5 измеряется отдельно от этих показателей.

На 120 последовательных HTTP-запросах после запуска демо p50 составил 3,74 мс, p95 — 10,06 мс, максимум — 12,15 мс. Замер включает разбор запроса, подбор и передачу JSON. Использовано по одному подтверждённому примеру на сценарий.

## Регрессия основного поиска и сценарий в браузере

На всех 130 запросах совпали позиции эталонов для гибрида, E5-large и BM25. У гибрида HitRate@4 составил 98 из 130 запросов, MRR@4 — 0,663, nDCG@4 — 0,573. Прошли 32 автоматических теста. Повторный вызов агента из теста выполнялся с заблокированным чтением XML. [Замер основного поиска](search-regression.json)

В локальном демо проверены подсказки категорий и производителей, доступность фильтров ПО в конкретной категории, повторный подбор по изменённым условиям, отмена предыдущего запроса и состояние «Не найдено». Для диагностики одного товара можно добавить `debug=1` к `GET /api/recommend?offer_id=501535`.

На P1 остаются обогащение соответствий APC, дополнительные паспорта сумок и лицензий, а также данные о вариантах закупки для тарифов с неоднозначными диапазонами.
