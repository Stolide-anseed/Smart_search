Материалы для оценки проекта «Умный поиск по каталогу Softline»
Состояние проекта на 26 ноября 2026 года. Пути указаны от корня распакованного архива softline-review.zip.

1. Исходное ТЗ от Softline

Задача трека «Аналитик данных» ИИкузницы — улучшить поиск магазина store.softline.ru и помочь покупателю найти сопутствующие решения. Поиск должен понимать намерение, опечатки и жаргон, различать близкие по тексту товары и проверять условия покупателя. Бизнес-цель — сократить случаи, когда клиент не находит нужный товар, и увеличить допродажи. На кик-оффе заказчик обозначил нагрузку около 500 поисковых обращений в сутки.

В ТЗ указано минимум четыре товара. Организаторы уточнили, что речь о разных продуктовых семействах. При двух прямых попаданиях можно дополнять выдачу двумя совместимыми допродажами. Когда точного товара нет, заказчик ожидает подходящий аналог. Неподходящий товар считается недопустимой ошибкой. Для допродаж нужна программная проверка характеристик. Снимка цен и доступности из фида достаточно. Объяснение рекомендации и аналитика промахов дают дополнительное преимущество.

Критерии трека — соответствие задаче партнёра, корректность технической реализации, потенциал внедрения, степень готовности продукта, агентность решения и экономика эксплуатации. Заказчик может выделить одно решение по задаче для рассмотрения пилота с бонусом 6 баллов. В дополнительных ответах для выбора на пилот отдельно отмечено качество процесса допродаж. Интерфейс играет демонстрационную роль.

Источники — исходные слайды «ИИкузница_—_Умный поиск на сайте.pdf», уточнения по кик-оффу и ответы организаторов в README.md.

2. Текущий репозиторий проекта

Снимок проекта в softline-review.zip содержит исходники softline_search/, тесты tests/, README.md, requirements.txt и материалы проверки.

- Индексация. catalog.py читает XML потоком. Индекс .search-index.sqlite3 содержит 44 601 предложение с available=true, метаданные карточек, SQLite FTS5 для BM25 и векторы multilingual-e5-large.
- Ранжирование. E5-large ищет по смыслу. BM25 использует текст и артикулы. Гибрид объединяет места через RRF с весами 0,7 и 0,3. Нормализатор исправляет раскладку, опечатки и жаргон. Затем поиск проверяет условия по данным XML и отбирает до четырёх разных семейств. При наличии свободных мест показывается помеченный резерв с неподтверждёнными условиями.
- Интерфейс и API. Локальная команда demo поднимает браузерную страницу. GET /api/search?q=... возвращает разбор запроса и карточки. GET /api/recommend?offer_id=... подбирает сменную батарею для ИБП APC.
- Текущая допродажа. Поле «Совместимая батарея» у ИБП сверяется с полным артикулом батареи того же производителя. Выдача содержит цену из фида, ссылку и объяснение. На этом снимке подтверждены три пары. Первое обращение по конкретному ИБП перечитывает XML, повторные обращения в демо используют кэш.
- Следующий этап по согласованному плану. Добавить необязательные фильтры и кнопку «Подходит к этому товару». Агент получает исходный запрос, ID товара и фильтры, выбирает сценарий ИБП → батарея, ноутбук → сумка или офисный пакет → антивирус и обращается к подготовленному индексу. При отсутствии прошедших проверку товаров ответ — «Не найдено».

Текущая реализация прошла 11 автоматических тестов. Для запуска после распаковки подготовьте окружение по README.md, выполните python -m softline_search build-index и запустите python -m softline_search demo. Индекс строится из вложенного XML.

3. Исходный XML-каталог

Полный файл Mindbox.yml.gz.xml включён в архив. Это YML в текстовом формате XML, около 292 МБ до сжатия. Дата снимка — 25 ноября 2026 года, 14:12.

- 136 040 предложений, 44 601 с available=true. У всех доступных на этом снимке предложений положительная цена. Во всём фиде положительная цена указана у 55 771 оффера.
- 9 311 записей в иерархии категорий. group_id заполнен у 127 915 офферов и даёт 4 413 разных идентификаторов групп. У остальных при дедупликации учитываем производителя, категорию и артикул.
- Среди доступных предложений 494 ИБП, 241 сменная батарея для ИБП, 44 ноутбука, 29 сумок и чехлов, 8 323 антивирусных лицензии для организаций.
- Один элемент offer описывает конкретный SKU. Внутри есть название, вендор, артикул, категория, описание, цена, валюта, ссылка и параметры. Варианты продукта связываются через group_id. Например, лицензии AnyDesk Solo и Standard относятся к группе 306539.
- Пример связи для допродажи. У ИБП APC SRT2200RMXLI-NC (82106) указан параметр «Совместимая батарея» со значением RBC141. Он сопоставляется с артикулом APCRBC141 (129441) в категории сменных батарей. Цена батареи по снимку — 37 950 ₽.

4. Текущие результаты поиска

Основная выборка — outputs/softline-combined/test_queries_combined.xlsx. На листе Sheet1 находятся 130 запросов и 542 размеченных соответствия на уровне офферов. Для семейной оценки они объединяются в 393 соответствия «запрос — семейство». В выборке есть жаргон, опечатки и запросы с несколькими эталонами. Десять исходных примеров заказчика приложены отдельно в «Выборка поисковых запросов.xlsx».

Повторный замер 26 ноября 2026 года. Все 130 запросов сопоставлены с эталонами. Считаются подтверждённые результаты без резерва. HitRate@4 — доля запросов с хотя бы одним эталонным семейством в первых четырёх позициях. Recall@4 — средняя доля найденных эталонных семейств на запрос.

Попадания гибрида

- «антивирь для дома» — эталонные семейства на местах 1 и 3, первым показан Dr.Web Security Space.

Промахи гибрида

- «софт для айпи-телефонии» — среди эталонов Brekeke PBX, первым показан световой индикатор Yealink BLT60. Эталонных семейств в топ-4 нет.
- «ocr для сканов» — среди эталонов Wondershare PDFelement, первым показан курс «Станочник, Заточные станки». Эталонных семейств в топ-4 нет.
- «рэковый сервак» — среди эталонов DEPO Storm 3470S2A, первым показан DEPO Storm 3470Z1A. Совпадение по эталонному семейству не засчитано.

Скорость прогретого гибридного поиска с проверкой условий на этом стенде — p50 139 мс, p95 434 мс по 130 последовательным запросам. Замер включает нормализацию, ранжирование и проверки. Загрузка модели и XML выполнена перед замером. Результаты по каждому запросу, позиции трёх методов и параметры замера лежат в evidence/evaluation-results.json.

Воспроизведение оценки — python -m softline_search evaluate --queries "outputs/softline-combined/test_queries_combined.xlsx".

6. Ограничения проекта

- Команда — один участник.
- Питч прототипов назначен на 2 декабря 2026 года по исходным слайдам ТЗ. На дату этого файла до питча шесть календарных дней. Отдельный срок загрузки проекта требует уточнения.
- Партнёр предоставляет XML-снимок и примеры запросов. Готовые товарные связки и API-интеграции предстоит реализовать команде. Сайты вендоров подходят для подтверждения характеристик. Организаторы оставляют выбор подхода и моделей участникам. Размещение на витрине и масштабирование относятся к дополнительным задачам.
- Демостенд — Windows, Python 3.13.3, NVIDIA GeForce RTX 4060 Laptop с 8 ГБ видеопамяти и около 31 ГБ доступной системной памяти. Текущий замер выполнен на CUDA. Доступен запуск на CPU, для него скорость измеряется отдельно.
- Эмбеддинги, BM25, проверка условий и подбор батареи выполняются локально. Внешняя плата за модель на запрос составляет 0 ₽ в текущей конфигурации. Затраты на оборудование и его эксплуатацию оцениваются отдельно.
