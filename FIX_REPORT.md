# Softline AI Search после ревью

27 ноября 2026, снимок `Mindbox.yml.gz.xml`, 291 988 701 байт. Для живого сравнения использованы GPT-6 Luna и настроенный ProxyAPI. Сетевой бюджет исправленного агента составляет 10 секунд. [Исходное ревью](REVIEW_REPORT.md)

## Что исправлено

- Клик «Подходит к этому товару» запускает полный локальный подбор по XML, паспортным данным и проверенным фактам SQLite. Если найдено подходящее предложение с ценой и наличием, сервер возвращает его сразу. GPT подключается, когда у потенциально полезного предложения есть конкретный устранимый пробел в характеристиках.
- GPT выбирает допустимый инструмент и путь к документации. Сервер проверяет сведения, сохраняет подтверждённый факт и повторно валидирует всех кандидатов. Сервер определяет итоговую выдачу, включая товары, которые отсутствуют в финальной селекции GPT. Совместимые позиции сохраняются при таймауте и HTTP 429.
- ASUS идентифицируется по отдельным полям артикула, модели предложения и корпуса. Таблицы производителя читаются по точному столбцу модели. Размеры приводятся к миллиметрам, а для документированного диапазона толщины берётся верхняя граница. Снимки таблиц Zenbook, VivoBook и ExpertBook включены в тесты.
- В Office → антивирус учитываются покрытие, цена покупки, срок и тип покупателя. Для сопоставимых редакций PRO32 пакет с большей ценой и лишними местами уступает варианту с достаточным покрытием и теми же или дополнительными функциями. При неизвестном покупателе показывается условие продажи для юрлица. [Сравнение редакций PRO32](https://pro32.com/ru/business/actions/prokachay-uroven-zashchity/)
- В API есть отдельные поля режима, исхода подбора и технической ошибки. Журнал считает выполненные проверки и отражает подтверждённые, отклонённые и неизвестные результаты. В отладочном ответе доступны причины и длительности локальной проверки, GPT, поиска, скачивания, извлечения, валидации и ранжирования.
- Карточка использует снимок запроса и фильтров, с которыми была показана. Новый поиск отменяет предыдущий запрос допродажи, а опоздавший ответ не меняет актуальный интерфейс. Для похожих товаров точный артикул выбранной позиции снимается с ограничений, остальные явные требования сохраняются.

## Эксперименты A–D

Восьмёрка фиксирована по товару и контексту. Прогоны C и D используют одну временную базу, пустую перед C. В каждом варианте по всем покрытым случаям был хотя бы один доступный товар с ценой.

| Прогон | Покрытие | Подходящих из проверенных пар | p50 | p95 | Вызовов GPT | Средняя стоимость клика |
|---|---:|---:|---:|---:|---:|---:|
| A, исходные правила | 4/8 | 7/7 | 0,17 мс | 5,79 мс | 0 | 0 ₽ |
| A, исходный GPT | 5/8 | 7/7 | 5,03 с | 11,38 с | 32 | 0,4763 ₽ |
| B, исправленные правила | 6/8 | 9/9 | 0,12 мс | 3,38 мс | 0 | 0 ₽ |
| C, адаптивный агент, холодный кеш | 7/8 | 11/11 | 1,60 мс | 7,04 с | 2 | 0,00257 ₽ |
| D, повтор с прогретым кешем | 7/8 | 11/11 | 1,41 мс | 7,80 мс | 0 | 0 ₽ |

В C агент понадобился для одного товара. Три из восьми старых онлайн-подборов завершились fallback, в C и D таких срабатываний было ноль. Среднее число позиций в B и C составило 1,125 и 1,375. Precision относится к размеченным парам этих прогонов. На малой выборке p95 C соответствует самому медленному запросу.

На совпадающих 118 товарно-контекстных случаях локальное покрытие выросло с 38 до 40. Для ноутбуков с контекстом по умолчанию результат изменился с 24/43 до 26/43, для ИБП составил 3/25, для офисных пакетов без уточнений — 1/6. Локальный p95 по всем 118 случаям составил 4,25 мс. На 36 размеченных случаях совпала маршрутизация, а все 27 предложенных размеченных пар оказались совместимыми. ### Живое обогащение Lenovo

Для `460304` и артикула `82RK013NRK` первичная проверка зафиксировала отсутствие габаритов. GPT вызвал `search_vendor_specs`. Сервер проверил связь артикула с IdeaPad 3 15IAU7, скачал паспорт и извлёк 359,2 × 236,5 × 19,9 мм. Готовая селекция GPT была пустой. При полной повторной проверке сервер подтвердил `498147` и `498146`. Повторный клик использовал кеш и вернул те же позиции. [Подтверждение артикула Lenovo](https://pcsupport.lenovo.com/us/en/products/laptops-and-netbooks/3-series/ideapad-3-15iau7/82rk/82rk013nrk/repair), [паспорт Lenovo](https://psref.lenovo.com/syspool/Sys/PDF/IdeaPad/IdeaPad_3_15IAU7/IdeaPad_3_15IAU7_Spec.PDF)

Прогон занял 7,04 с. Время двух вызовов GPT составило 3,46 с, загрузка официальных документов заняла 3,26 с, извлечение факта — 302 мс. Hosted search не понадобился. По фактическому потреблению и тарифу за этот клик рассчитано 0,020562 ₽. Сумма зависит от доли кешированных токенов. [Тариф ProxyAPI](https://proxyapi.ru/models/openai), [срез тарифов](outputs/softline-p1/proxyapi-rates.json)

Пример локального выхода — `530901`. Сервер проверил размеры по справочнику, вернул обе HP в режиме `local` и сделал ноль вызовов GPT. Отсутствие батареи для `82161` возвращается как обычный `completed_empty`.

## Поиск, интерфейс и тесты

- По 130 запросам совпали ID и порядок подтверждённых и резервных позиций для E5, BM25 и гибрида. Для гибрида HitRate@4 составил 75,38%, Recall@4 — 55,31%, nDCG@4 — 57,33%. Четыре подтверждённых семейства есть в 92/130 случаях (70,77%). С помеченным резервом показаны четыре позиции в 94/130 случаях (72,31%). [Результаты по каждому запросу](outputs/softline-fix/search-evaluation.json)
- `/api/similar?offer_id=473582&q=EP2-06605` вернул офисный пакет MobiOffice `481907` из смежной категории. В объяснении отмечены различия производителя и цены.
- В Edge проверены редактирование формы без нового поиска, повторный клик, новый поиск во время подбора и отмена запоздавшего ответа. Неизвестный ID дал HTTP 404, некорректное значение фильтра — HTTP 400. [Браузерный замер](outputs/softline-fix/browser-smoke.json)
- **77 автоматических тестов прошли**. Новые проверки покрывают точные столбцы ASUS, сохранение результата при пустом ответе GPT и HTTP 429, совместное выполнение одинаковых запросов и коммерческий отбор для 1, 5 и 36 устройств. Проверка синтаксиса `app.js` прошла.

## Ограничения

Для 28 из 30 позиций сумок нужны полные размеры отделения. Две HP имеют подтверждённые предельные габариты. Для 17 из 43 ноутбуков сопоставимой выборки ещё нужны данные о корпусе. Кейс Lenovo показывает вклад живого обогащения на одном товаре. Расширение источников и фактов остаётся основным способом поднять покрытие.

Для 38 запросов основного поиска в текущей выдаче меньше четырёх подтверждённых семейств. Точный артикул остаётся отдельным результатом поиска, аналоги доступны на карточке. Дополнительные позиции с непроверенными требованиями отображаются с пометкой. Отменённый в браузере сетевой запрос на сервере ограничен дедлайном и лимитом параллельных запусков.

## Воспроизведение

Команды выполняются из корня проекта. Для живого прогона нужны локальный `.env` с ключом, существующий индекс и тот же снимок XML.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests
.\.venv\Scripts\python.exe evaluate_review_fixes.py --live --timeout 10
.\.venv\Scripts\python.exe -m softline_search evaluate --queries "outputs/softline-combined/test_queries_combined.xlsx"
.\.venv\Scripts\python.exe -m softline_search demo --port 8871
```

Для демонстрации найдите `90NB14W1-M01Z50`, `90NB10N3-M02KZ0`, `82RK013NRK`, `SRT2200RMXLI-NC` или `EP2-06605`. На карточке откройте «Подходит к этому товару» и журнал действий. Для сравнения офисных пакетов откройте «Похожие товары» у `EP2-06605`. Запуск `evaluate_review_fixes.py` без `--live` выполняет локальный замер.
