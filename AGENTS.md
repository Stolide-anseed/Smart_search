Правила экономии контекстного окна:

- Не сканируй весь репозиторий без необходимости.
- Не перечитывай файлы, если их содержимое уже известно и не изменилось.
- Используй точечный поиск по функциям и классам.
- Не загружай целиком датасеты, JSON, CSV и объёмные логи.
- Не выводи полный код файлов после их изменения.
- Запускай целевые тесты вместо полного тестирования после каждого изменения.
- Избегай повторного анализа уже принятых архитектурных решений.
- Обновляй PROGRESS.md после каждого завершённого этапа.
- При заполнении 70–80% контекстного окна сохраняй состояние работы, если информация о размере контекста доступна.
